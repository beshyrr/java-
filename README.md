## 📌 Description

Ce projet correspond au **Prosit 4** et se concentre sur l’**héritage** entre classes (classes mères / filles) dans le cadre de la POO.

## 🚀 Contenu principal

- Classe(s) de base (par exemple `Animal`).
- Classes dérivées (par exemple animaux spécifiques, rôles spécialisés, etc.).
- Code de test montrant la réutilisation de code grâce à l’héritage.

## 🎯 Objectifs pédagogiques

- Comprendre la relation **« est un »** (is-a).
- Factoriser du code commun dans une classe mère.
- Utiliser le mot-clé `extends` en Java.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
