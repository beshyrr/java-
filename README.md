# 🐯 Programmation Java - Prosit 11

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)

## 📌 Description

Ce projet correspond au **Prosit 11** et rassemble plusieurs notions (POO, collections, exceptions, interfaces, etc.) dans une petite **application de gestion** (zoo, société, étudiants, … selon la branche).

## 🚀 Contenu principal

- Classes métier (ex : `Employee`, `Departement`, `Student`, etc. selon le code).
- Classes de gestion (ex : `SocieteArrayList`, `DepartementHashSet`, `AffectationHashMap`, `Management`, etc.).
- `Main.java` / `Management.java` : scénarios de test ou menu de gestion.

## 🎯 Objectifs pédagogiques

- Intégrer plusieurs notions Java dans un même projet cohérent.
- Organiser les classes par responsabilité.
- Approcher une architecture plus réaliste et modulaire.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
