## 📌 Description

Ce projet correspond au **Prosit 12** et propose une version plus complète de l’application de gestion (zoo, société, étudiants…), en combinant **interfaces**, **collections avancées** (`ArrayList`, `HashSet`, `HashMap`) et **exceptions personnalisées**.

## 🚀 Contenu principal

- Interfaces de gestion (par exemple `IGestion`, `IDepartement`, etc.).
- Implémentations concrètes : `SocieteArrayList`, `DepartementHashSet`, `AffectationHashMap`, `StudentManagement`, `Management`…
- Exceptions personnalisées : `InvalidAgeException`, `ZooFullException`, ou autres selon la branche.
- `Main.java` / `Management.java` : scénarios de test ou menu de gestion.

## 🎯 Objectifs pédagogiques

- Maîtriser l’utilisation conjointe de plusieurs notions avancées de Java.
- Concevoir une architecture modulaire avec interfaces et classes de service.
- Gérer proprement les erreurs via des exceptions dédiées.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
