## 📌 Description

Ce projet illustre les concepts fondamentaux de la **programmation orientée objet en Java** à travers un exemple de gestion de zoo.

## 🚀 Contenu

- `Zoo.java` : classe de gestion d’un zoo (liste d’animaux, opérations de base).
- `ZooManagement.java` / `Main.java` : point d’entrée du programme.

## 🎯 Objectifs pédagogiques

- Approfondir la création de classes et d’objets.
- Manipuler des listes d’objets.
- Structurer un petit projet Java autour d’un cas métier (zoo).

## ⚙️ Technologies

- Java (JDK 17+)
- IntelliJ IDEA
