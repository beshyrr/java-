## 📌 Description

Ce projet correspond au **Prosit 9** et se concentre sur `HashSet` et la notion d’**unicité** des éléments.

## 🚀 Contenu principal

- Utilisation de `HashSet` pour stocker des objets sans doublons (ex : départements, employés, animaux, etc.).
- Redéfinition éventuelle de `equals` / `hashCode` dans les classes concernées.
- Tests d’ajout de doublons et vérification du comportement du `Set`.

## 🎯 Objectifs pédagogiques

- Comprendre le fonctionnement d’un `Set`.
- Gérer l’unicité grâce à `equals` / `hashCode`.
- Choisir entre `List` et `Set` selon le besoin fonctionnel.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
