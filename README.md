## 📌 Description

Ce projet correspond au **Prosit 5** et met l’accent sur le **polymorphisme** : une même référence peut pointer vers différentes implémentations concrètes.

## 🚀 Contenu principal

- Hiérarchie de classes (ex : `Animal` et ses sous-classes).
- Méthodes redéfinies avec `@Override`.
- Tests montrant des appels polymorphes via une référence de type parent.

## 🎯 Objectifs pédagogiques

- Comprendre la **liaison dynamique** en Java.
- Utiliser des tableaux / listes de type parent contenant des objets enfants.
- Gérer des comportements différents via des méthodes redéfinies.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
