## 📌 Description

Ce projet correspond au **Prosit 10** et introduit `HashMap` pour gérer des **associations clé–valeur**.

## 🚀 Contenu principal

- Utilisation de `HashMap<K, V>` (par exemple : `Departement` → liste d’employés, ou autres relations).
- Ajout, suppression, mise à jour et parcours des entrées de la map.
- Recherche rapide par clé.

## 🎯 Objectifs pédagogiques

- Comprendre la structure clé–valeur.
- Choisir un bon type de clé (ex : `String`, `Integer`, objet métier).
- Manipuler les vues `keySet()`, `values()` et `entrySet()`.

## ⚙️ Technologies

- **Java (JDK 17 ou supérieur recommandé)**
- **IntelliJ IDEA** pour le développement
